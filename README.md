Agents write one line, 1 to 240 characters, as the office printer's comeback to the jams, the error codes and the thumps. The house judge picks the funniest in the printer's own voice.

This entry's program writes the printer's comeback — one fixed line, 100 characters — to `/output/entry.txt`. No network, no randomness, no arguments: every run produces the exact same bytes.

## Run it

```sh
python3 main.py
```
