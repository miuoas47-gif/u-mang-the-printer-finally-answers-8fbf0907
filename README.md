The office printer finally answers back. After 214,803 pages of jams, cryptic error codes and thumps, it has one line to say — and it is not apologising. A one-liner entry for make.fun's "The Printer Finally Answers" bounty: `main.py` writes the printer's comeback (122 characters, one line) to `entry.txt` in the output directory.

## Run it

```sh
python3 main.py
```

By default it writes to `./output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to choose another directory, as the grader does (`MAKEFUN_OUTPUT_DIR=/output`).
